# Working name and positioning

## Working name

**Livehelm**

Use this name in docs, repo, and temporary legal drafts until a real name is chosen.

Tagline:

> Plan. Control. Respond. Deliver.

One-line description:

> One operational platform for planning, controlling, running, and reviewing live events.

## Why this working name

- It sounds like a control position, not a ticket shop.
- It is specific enough to search.
- It avoids festival-only language.
- It does not promise AI, magic, or “all-in-one event success”.

It is a working name, not a brand lock.

## Name collisions to check before you print anything

Before buying a domain or filing a trade mark, search:

- UK IPO trade marks
- EUIPO
- USPTO
- Companies House
- App stores
- Domain availability
- Kubernetes Helm and other strong “Helm” products — this is why the working name is **Livehelm**, not Helm

## Alternative names if Livehelm fails clearance

| Name | Tone | Risk |
| --- | --- | --- |
| Eventhelm | Clear, a bit plain | Similar to Livehelm |
| Opsroom | Literal | Generic, hard to trade mark |
| Groundline | Calm, operational | May feel telecoms |
| Marshal | Event-native | Common word |
| Dutydesk | Control-room native | Feels small / municipal |
| Sitecontrol | Literal | Generic |
| Runorder | Strong for programme | Weak for incidents |
| Controlpost | Very operational | Long, generic |

Do not spend a month on naming. A cleared name and a serious product beat a clever name.

## Positioning

Livehelm is for the people who are responsible when the event is live.

It is not:

- a consumer ticket marketplace
- a wedding planner
- a generic project-management tool with an events skin
- a radio replacement
- an emergency-service command system
- a medical-record system
- a fundraising CRM

It can later connect to some of those. It should not become them.

## Category language to use

Use:

- event operations platform
- live event control
- single operational picture
- control log
- incident, task, programme, site

Avoid:

- “AI-powered event magic”
- “the operating system for culture”
- “all your event needs in one place”
- “next-gen”
- “disrupt”

## Who we compare against in conversation

People will compare Livehelm to WhatsApp, paper logs, Excel, radio, and generic tools such as Monday, Notion, or Slack.

The honest comparison is:

> Those tools can hold messages or rows. They cannot give event control one live picture with permissions, audit, map, and handover.

Do not claim to replace radio. Radio stays. Livehelm records what radio decided and what happened next.
