# Control operator one-pager

Hand this to someone sitting in event control. Not a training course.

## What this system is

The live picture. Radio still exists. If you said it on the radio and it matters, it also goes in here.

## Every time something happens

1. **Log it** — department, short message, action taken. Time is automatic.
2. If it needs assigning, a timeline, or a close-out — **promote to an incident**.
3. If someone must go and do a job — **create a task**.

## Priorities

CRITICAL, HIGH, MEDIUM, LOW — say the word, do not rely on colour.

## You can

- Create log lines
- Create and update incidents
- Create and update tasks
- See the map, programme, and Live screen
- Message channels

## You cannot

- See safeguarding case details
- See medical treatment notes
- Activate an emergency playbook
- Change organisation billing or delete history

If you hear a safeguarding concern: log “Safeguarding — [location] — lead informed” and tell the safeguarding lead. Do not type the person’s story into the open log.

## Emergencies

Open the playbook. Call the contacts. A manager activates the banner. The software does not decide.

## If the screen is stale

Look at the time on the banner. Refresh. If it is still wrong, use radio and paper timestamps. Do not invent catch-up later without saying “late entry”.

## Handover

Before you leave: open incidents, criticals, open urgent tasks, last attendance number, any active emergency, and what is ON STAGE now.
