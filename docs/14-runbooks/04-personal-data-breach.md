# Personal data breach

This is a legal clock. Call counsel if you have them.

1. Contain: rotate secrets, revoke sessions, lock the hole.
2. Record: what, when, which orgs, which data types (especially medical/safeguarding).
3. Do not notify Twitter first.
4. Assess risk to people.
5. If required, notify ICO (UK) within the statutory period and the customer controller without delay.
6. EU/US customers may have additional notices.
7. Write what you will change.

Do not delete audit logs to “clean up”.
