# End-to-end tests

Playwright against local or staging:

1. Owner creates event
2. Invites operator
3. Operator signs in (MFA test can be staged-off for e2e, but then a separate MFA test exists)
4. Files a log line
5. Promotes to incident
6. Adds two actions and closes
7. Creates a task and completes it
8. Adds a location and sees it in typeahead
9. Updates programme
10. Generates report counts

Keep e2e few and stable. UI-class flakiness is not an excuse to skip RLS tests.
