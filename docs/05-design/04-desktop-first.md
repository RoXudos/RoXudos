# Desktop first

Founder decision: control-room desktop first, mobile later.

## FPR breakpoints

| Width | Expectation |
| --- | --- |
| ≥ 1600px | Full live mosaic |
| 1280–1599 | Live mosaic stacks to two columns |
| 768–1279 | Tablet: Live becomes a vertical stack; usable in a production office |
| < 768 | Do not pretend to be the field app. Show a simplified Live + quick log + incident list. No tiny mosaic |

Do not spend FPR time polishing a phone visual design. Make it usable enough that a manager can open a link. Phase B is the field product.

## Keyboard

- `L` focus quick log
- `I` new incident
- `T` new task
- `/` search
- `Esc` close drawer

Document these on a `/help` page with one screen.

## Pointer

Large enough hit targets on the mosaic tiles. Operators may be using a cheap mouse on a shared PC.
