# Event membership and roles

## Steps

1. From the event, add an existing org member or invite a new email.
2. Assign one FPR role.
3. Changing a role is audited (before/after).
4. A user without event membership cannot open `/app/events/[id]/live` even if they are in the org (except Owner / Director if you decide they inherit. **Recommendation: Owner can open every event in the org. Other org members must be added to the event.**)

## Done when

A vendor-role user in Event A cannot open Event B in the same organisation.
