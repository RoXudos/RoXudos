# Event create

## Fields on create

- Name
- Type (preset module flags)
- Timezone (default `Europe/London`)
- Public dates
- Build / derig optional
- Venue name
- Expected attendance optional

After create, show module flags as toggles (advanced). Changing type later does not delete data; it only hides modules.

## Status

New events start `draft`. Owner/Director can move `draft → planned → build → live → closed → archived` with checks (see close playbook later).

## Done when

A festival and a charity event can both exist in one org with different flags. Navigation hides fundraising on the festival if the flag is off.
