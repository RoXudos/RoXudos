# Organisation and invite

## Steps

1. First user to complete setup creates an organisation (name, slug).
2. They become Organisation Owner.
3. Invite form: email + org role + optional event + event role.
4. Email sends an accept link.
5. Accept creates membership and profile.
6. Disabled members cannot sign in to that org.

## Empty state

“No teammates yet. Invite the event control manager.”

## Done when

Two browsers: owner invites a control operator; operator sees only that org; a third email not invited cannot join.
