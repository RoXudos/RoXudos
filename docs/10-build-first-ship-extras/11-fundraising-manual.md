# Charity fundraising (manual)

No payment processor in FPR.

## Fields on the event when `fundraising` flag is on

- Target amount
- Raised amount (manual)
- Participant count (manual)
- Volunteer count (can be derived from people kind=volunteer)
- Sponsor notes
- Currency (GBP default)

Show a simple tile on Live if the flag is on. Do not build Gift Aid filing.

## Done when

A charity event can show TARGET / RAISED / PARTICIPANTS as real stored numbers, updated by a permitted role, audited.
