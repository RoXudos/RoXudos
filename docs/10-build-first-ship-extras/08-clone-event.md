# Clone event

## Copies

- Site, zones, locations
- Department / role templates (not named people unless opted in)
- Emergency playbooks
- Programme structure (times shifted by a date delta, or cleared — ask on the clone form)
- Vendor list **without** last year’s documents unless opted in
- Module flags
- Weather thresholds
- Channel names

## Never copies

- Incidents, log, tasks, messages, alerts
- Check-ins
- Medical extras, safeguarding
- Audit
- Current attendance
- Emergency activations
- Reports

## Steps

1. “Clone” on a closed or archived event.
2. New name + year + date shift.
3. Job runs synchronously if small; queue if you already have a worker. FPR: sync is fine under a few hundred locations.
4. Audit the clone.

## Done when

Festival 2026 becomes Festival 2027 with a map and playbooks, and zero leftover incidents.
