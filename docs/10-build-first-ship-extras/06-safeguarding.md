# Safeguarding

Same DPIA gate as medical.

## Steps

1. Separate nav and tables.
2. Cases not in incident search.
3. No map pins.
4. Audit every details read.
5. Control operators can be told “raise to safeguarding lead” via a log line, not by opening the case.

## Done when

Search “welfare tent” as an operator does not return case bodies. The Safeguarding Lead sees the case.
