# Check in / out

## Steps

1. From a person or a dedicated desk screen: Check in / Check out.
2. Writes `checkins` row. Never overwrite history.
3. Live staff tile uses the derived on-site count.
4. Desktop is enough. Phone camera check-in is Phase B.

## Done when

Checking in 3 people moves the Live tile from 0 to 3. Checking one out moves it to 2.
