# Close event

## Checks before `live → closed`

- List open incidents (must confirm)
- List open tasks (must confirm)
- Active emergency must be stood down
- Attendance last value shown

Require a typed confirmation.

## After close

- Writes still allowed for late log lines? **Recommendation:** allow Control Manager to add log/incident for 24 hours with a “late entry” flag, then freeze operational writes except report/lessons.

## Done when

A closed event cannot be casually edited by a Control Operator.
