# Copy the bible into the product repo

1. Create `livehelm` as specified.
2. Copy the entire `/docs` tree from this profile repo.
3. Add a product README:

```md
# Livehelm

Event operations platform.

Documentation starts at [docs/README.md](docs/README.md).
```

4. After the copy, **stop adding product files to `RoXudos/RoXudos`**.
5. Optionally leave a link on the profile README.

The profile repo may keep a snapshot of the docs. The live bible is the one next to the code.
