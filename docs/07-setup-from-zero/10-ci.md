# CI

GitHub Actions on every PR:

1. `pnpm install --frozen-lockfile`
2. lint
3. typecheck
4. unit tests
5. (optional job) supabase test / RLS tests against a service container

On `main`:

6. Deploy to staging (Vercel does this if configured)
7. Playwright smoke against staging after deploy (later)

## Do not

- Run migrations against production from a PR
- Print secrets in logs
- Use `npm` in CI if the repo is `pnpm`

## Dependabot

Enable weekly npm + github-actions updates. Review them. Do not auto-merge.
