# Local machine

## Install

- git
- Node.js current LTS
- pnpm
- Docker Desktop or Docker Engine (for `supabase start`)
- GitHub SSH or gh auth
- 1Password CLI optional

## Check

```bash
node -v
pnpm -v
docker version
git --version
```

## Editor

VS Code or Cursor. Recommended extensions: ESLint, Tailwind, Playwright.

## Rule

Do not install production service-role keys on a shared machine.
