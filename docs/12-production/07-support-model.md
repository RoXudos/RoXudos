# Support model

FPR support is not 24/7 global NOC unless you sold that.

Write for each customer:

- Hours you will answer
- What is P1 (app down, cannot log incident)
- What is P2 (map tile ugly)
- Phone number for P1 during their event
- How they reach you without WhatsApp chaos (a shared status + `support@`)

Livehelm staff access to a customer event is break-glass only, reason required, audited.
