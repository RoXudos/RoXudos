# Definition of production

You may tell a customer “this is production” only when:

1. Pre-production checklist is green
2. Staging rehearsal passed
3. Restore drill done
4. Support hours exist
5. The modules they will use are not mocked
6. Legal docs are live URLs, not drafts in your head

A Vercel URL with test incidents is staging, even if it uses the production project by mistake. Do not do that.
