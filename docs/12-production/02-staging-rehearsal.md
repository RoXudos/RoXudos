# Staging rehearsal

Run a **tabletop plus screens** rehearsal. Four hours is enough.

## Cast

- Event Control Manager
- Control Operator
- Security Manager
- Medical Manager
- Safeguarding Lead (if module on)

Use dummy names. No real lost children.

## Script

1. Event goes `live`.
2. Log a fight at Gate 3. Promote to incident. Dispatch security.
3. Medical incident at Main Stage with extras (if on).
4. Task: toilets overflowing.
5. Programme change: support act delayed 15 minutes.
6. Wind threshold alert (insert snapshot).
7. Activate missing-child playbook. Stand it down.
8. Check in 10 staff. Check out 2.
9. Send a high-priority comms message.
10. Generate a report.
11. Hand over to a “next shift” using the report.

## Fail the rehearsal if

- Anyone used WhatsApp for a record that should have been in the log
- A role saw a restricted body
- Realtime was dead and nobody noticed
- Numbers on Live were wrong

Fix, then rehearse the failed scenes again. Do not “take it to the live event anyway”.
