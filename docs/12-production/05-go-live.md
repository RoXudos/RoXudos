# Go live — first real event

## Week before

- [ ] Customer DPA signed
- [ ] Users invited, MFA done for managers
- [ ] Map and programme entered
- [ ] Playbooks and contacts checked by the customer
- [ ] Support hours agreed
- [ ] Deploy freeze window written

## Day before

- [ ] Staging rehearsal notes closed
- [ ] Production health green
- [ ] Weather cron seeing the site lat/lng
- [ ] Attendance starts at 0 or last known, not a demo number

## During

- Founder or on-call watches Sentry, does not “improve the UI” on production
- Customer owns operational decisions

## After

- [ ] Close event flow
- [ ] Generate report
- [ ] Ask the success questions in the product metrics file
- [ ] Write improvements into the decisions log or a later-phase ticket — not into a panic rewrite
