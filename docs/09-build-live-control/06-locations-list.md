# Locations list

Build the searchable location directory **in the same slice as the map**, not after. The map is not the only way to pick a place.

## Steps

1. CRUD locations and zones with `map.update`.
2. Type enum from the maps architecture.
3. Typeahead component used by log, incident, task.
4. Accessibility flags on the location.

## Done when

You can file an incident at “Gate 3” before the polygon looks pretty.
