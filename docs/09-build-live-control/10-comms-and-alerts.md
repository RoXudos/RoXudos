# Comms and alerts

## Steps

1. Seed channels on event create.
2. Message list + composer.
3. High priority visually distinct.
4. Read receipts: who has opened a high-priority message.
5. Alerts table + bell + Live strip.
6. Permission `comms.priority` for high priority and `alert.send` for alerts.

## Done when

Control can send “Gate 2 closed — use Gate 3” to Security and see who has read it.
