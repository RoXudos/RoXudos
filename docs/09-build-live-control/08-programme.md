# Programme

## Steps

1. Stages CRUD.
2. Items with start/end, title, artist_name optional.
3. Compute NOW / NEXT / LATER in event timezone.
4. Live widget uses the same query.
5. Updates audited and pushed realtime.

## Empty

## Done when

Changing the headliner time updates NOW/NEXT on a second screen without reload (after realtime file).
