# Attendance and department status

## Attendance

FPR: a Control Manager types a number and a time. History of updates in audit. Show the last number on Live.

Later: import from a ticket vendor. Do not block FPR on that.

## Staff on site

Derived from check-ins (people slice). Until people check-in exists, show “—” not `0` if the people module has no check-ins yet. `0` is allowed only when the module is live and nobody is checked in.

## Medical / security status

Manager sets green/amber/red + one line. Audited. Shown on Live.

## Done when

Tiles on Live are either real numbers or an em dash. Never decorative fiction.
