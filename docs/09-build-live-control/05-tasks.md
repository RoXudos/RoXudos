# Tasks

## Steps

1. CRUD with permissions.
2. Status: open, in_progress, blocked, done, cancelled.
3. Comments + attachments.
4. Completion sets `completed_at`.
5. Live tile: count of not done.
6. From incident: “Create task” copies location and a title.

## Empty

“No open tasks. Create one from an incident or from here.”

## Done when

Facilities can be assigned “Toilet block overflowing”, move it to in progress, and complete it with a timestamp.
